# Caesar Cipher

A simple Python-based program that encrypts and decrypts messages using the classic Caesar Cipher algorithm. Shift letters by a specified number of positions to encode or decode text.

## ✨ Features

- Encrypt and decrypt messages
- Customizable shift value
- Interactive command-line interface
- Simple and beginner-friendly implementation
- ASCII-art visuals

## 🛠️ Tech Stack

- Python 3
- Python Standard Library

## 📂 Project Structure

```
Ceasar_Cipher/
├── main.py       # Main program logic
├── art.py        # ASCII art and visuals
└── README.md
```

## 🚀 Getting Started

**1. Clone the repository**

```
git clone https://github.com/Numan-Ahmad-Khan/Ceasar_Cipher.git
```

**2. Navigate to the project directory**

```
cd Ceasar_Cipher
```

**3. Run the program**

```
python3 main.py
```

## 🎯 How to Use

1. Choose `encode` to encrypt or `decode` to decrypt.
2. Enter your message.
3. Provide the shift value.
4. View the resulting message.
5. Choose whether to continue or exit.
